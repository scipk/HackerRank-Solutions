## Solve Me First

Complete the function `solveMeFirst` to compute the sum of two integers.

### Example
$a = 7$
$b = 3$

Return $10$.

### Function Description

Complete the `solveMeFirst` function with the following parameters:

* $int \space a$: the first value
* $int \space b$: the second value

#### Returns
- $int$: the sum of $a$ and $b$

### Constraints
$1 \le a, b \le 1000$

### Sample Input
```text
a = 2
b = 3
```

### Sample Output
```text
5
```
### Explanation
$2+3 = 5$
